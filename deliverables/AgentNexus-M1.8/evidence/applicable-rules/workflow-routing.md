# 项目类型工作流路由

开发前只读本路由。依据项目现有 README、依赖信息或用户目标中已经出现的证据判断是否匹配；不要为匹配额外读取大量文件，也不要扫描或通读所有子文件夹。匹配后只读对应流程入口；无匹配流程则跳过。这里不启用任何默认流程。具体流程仅在重复的实际任务形成稳定做法后增补。

匹配到类型也只选择当前阶段必要步骤，不自动安装增强模块或派发复审代理。早期优先验证方向，成熟后再逐步完善；简单改动直接做。

同一会话已读取且内容未变时沿用，不重复读路由或重新评估已明确的小改动。

| 项目类型/任务证据 | 匹配条件 | 流程入口 | 状态 |
|---|---|---|---|
| 新类型 | 已有材料能明确表明符合该流程触发条件 | 对应类型目录的 README | 尚无；按需增补 |
| 流程编写 | 正在为重复任务增补流程 | [_template/README.md](_template/README.md) | 模板 |
