# Q4.1 总体设计

本候选在独立目录复用 Q3/Q4 代码与证据，历史字节不变。初始方向是将 LOCAL_QUALIFICATION 的专用证书用途、用户独立核对的 DER SHA256 pin、资格 CMS、部署 CMS、安装后运行期检查绑定在一起；PRODUCTION_RELEASE 保留原签发合同，并额外拒绝本地资格证书。

资格计划与部署批准使用不同文档、不同 CMS 和不同用户确认。签署计划不能安装；部署签名也不能导入真实 Key 或调用 Provider。所有本地材料固定 QUALIFICATION_ONLY，四项真实/生产权限为 false。安装器默认只读，Apply 要求独立管理员会话与最后一次具体范围确认。

独立 WinForms Signer 读取并锁定全部候选文件，显示原始文档、实际系统变更和摘要；不接收私钥、PFX、密码、自动批准参数或环境变量密钥。实际签名仅在用户控制、开发代理不可访问的独立离线 Windows 会话/设备，通过 Certificate Store/CNG 密钥句柄执行。非导出和 TPM 并不证明同 SID 恶意进程不能调用密钥，当前机器上的可信用户在场保证尚未验证，不能宣称高保证。

先冻结安装字节，再制作计划，再签署计划，之后制作并单独签署部署批准。系统变更、安装器和签名策略的 Hash 也进入签署绑定。签名结果不能回写已冻结载荷；需要改变时生成新候选、重新 Hash、重新审批。签名不改变程序 PE 字节；CMS 不等于 Authenticode。

本地 epoch 单独提升至 4，并配合一次性部署 ID 与受保护、先于系统安装创建的消费收据拒绝重放。删除/回退受保护状态的管理员不在此承诺中；不把文件收据称为 TPM 单调计数器。Q3 生产规则不会因本地 epoch 被降低。

本轮只执行代码、构建、临时内存模拟证书测试、验证器与只读预检。最终保留 UNSIGNED / NO-GO，实际公开证书 pin、有效签名、独立用户批准尚不存在。70 项 OS 测试和 19 类生产证据保持 NOT_RUN。
